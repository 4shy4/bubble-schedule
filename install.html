按你的设备选一条路

安卓手机 / 平板 （最省事）

  1. 点上面的下载安卓版 APK，下到手机里（或用电脑下载后拷进手机）。
  2. 点开这个文件安装；系统会问一次「允许安装未知应用」，同意即可。
  3. 如果你之前装过调试版，会提示「应用未安装」—— 先卸载旧的那个再装（卸载会清掉手机上那份数据）。

闹钟走系统闹钟（能穿透省电模式）；日程存在 App 的私有目录里。

iPhone / iPad

这个 APK 是安卓的，iPhone 用不上。你有两条路：

① 网页版（只想在手机上看看、用用）： 在你自己的电脑上把程序跑起来（git clone 后 node server/main.js --lan， 启动日志里会打印一个局域网地址），然后在 iPhone 的 Safari 里打开那个地址 → 分享 → 添加到主屏幕。它就是一个能全屏、能收通知（iOS 16.4+）的网页版， 数据仍然在你自己电脑上。

② 原生 App（想要真闹钟）： ios/ 是一个 Swift 外壳（AlarmKit + WebKit），仓库里没有预编译的 IPA， 也不提供免签名的安装方式 —— 需要你自己装 Xcode、生成工程、填上你自己的签名再装。
